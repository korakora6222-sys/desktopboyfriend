# 萌宠桌面 · 第一版 施工计划（Implementation Plan）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 做一个安卓 App：桌面上悬浮一张静态帅哥小圆脸，点一下就能用中/英文语音跟他对话，他用手机自带声音回应，人设是粘人小狗系、以情感陪伴/安抚情绪为主，能记住用户。

**Architecture:** 原生安卓（Kotlin）。一个前台服务(Foreground Service)负责在桌面上用 WindowManager 画悬浮窗（那张脸）。点脸 → 用安卓自带 SpeechRecognizer 把用户的话转成文字 → 拼上人设与记忆后调用 DeepSeek 生成回话 → 用安卓自带 TextToSpeech 念出来。API Key 与昵称等存在本机 SharedPreferences。用 GitHub Actions 云端编译出 APK，用户下载安装。

**Tech Stack:** Kotlin, Android SDK (minSdk 26 / targetSdk 34), Gradle (Kotlin DSL), OkHttp（调 DeepSeek）, Kotlin Coroutines, Android SpeechRecognizer（语音识别）, Android TextToSpeech（语音合成）, JUnit + Robolectric/MockWebServer（单元测试）, GitHub Actions（云端打包）。

**Spec:** `萌宠桌面/方案-第一版设计.md`

## Global Constraints

- 语言：代码注释与用户可见文案用中文；变量/函数名用英文。
- 第一版语音识别与合成一律用**安卓系统自带 API**（免费、支持中英文），不接第三方语音服务。
- DeepSeek API Key 由用户在 App 内设置页粘贴，存 SharedPreferences，**绝不写死在代码里、绝不提交进 Git**。
- 那张脸**静态**，只做表情图切换，**不做口型/嘴部动画**。
- 回应**只输出语音**，不在悬浮窗展示回复文字（可在调试期临时打日志）。
- minSdk = 26（Android 8.0），targetSdk = 34。
- 悬浮窗类型用 `WindowManager.LayoutParams.TYPE_APPLICATION_OVERLAY`。
- 第一版交互为"点一下脸再说话"；语音唤醒("像 Siri 一样召唤")属第二版，本计划不实现。
