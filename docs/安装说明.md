## 第一次要做的四件事（之后就一劳永逸）

### ① 拿到安装包（APK）
代码要先"云端打包"成一个手机能装的文件。这一步我会带你：
1. 注册/登录一个 **GitHub** 账号（免费）。
2. 把"萌宠桌面/app-android"这套代码传上去（我给你具体命令，复制粘贴即可）。
3. GitHub 会**自动编译**，几分钟后在网页上生成一个 `mengchong-desktop-apk`，下载下来就是安装包。

> 打包过程你什么都不用装，全在网上自动完成。

### ② 把安装包传到安卓手机
- 用微信/QQ 传给自己、或用数据线拷过去都行。

### ③ 允许"安装未知来源的应用"
- 点开那个 APK，手机会提示"为了安全，禁止安装未知应用" → 点**去设置** → 打开**允许来自此来源** → 返回 → 继续安装。
- （不同手机文字略有差别，找到"允许安装/未知来源"打开即可。）

### ④ 打开 App，给三个权限 + 填钥匙
打开"萌宠桌面"后：
1. 点 **去设置**，把你的 **DeepSeek API Key** 粘进去、填上你想让他怎么叫你（如"宝贝"），保存。
2. 回到首页点 **把他放到桌面**，会依次让你允许：
   - **显示在其他应用上层**（悬浮窗）——必须开，他才能待在桌面。
   - **麦克风**——必须开，他才能听你说话。
   - **通知**——建议开，让他更不容易被系统关掉。
3. 桌面上就会出现他啦！**点他一下 → 说话 → 他用声音回你。**

## 让他更"赖得住"（防止被手机关掉）

安卓为了省电，会偷偷关掉后台的 App。想让他一直在、开机自动回来，去手机设置里给"萌宠桌面"开这几项（不同品牌位置不同）：
- **自启动 / 允许开机启动**
- **省电策略 → 不限制 / 无限制**
- **后台运行 → 允许**

> 小米、华为、OPPO、vivo 这类国产手机尤其要设置这个，否则重启后他可能不会自动出现。

---

## 常见问题

- **点他没反应 / 说没听清**：确认麦克风权限开了；说完稍等一下让他反应。
- **他不说话**：确认设置里 DeepSeek 钥匙填对了、手机能上网。
- **他的声音**：第一版用的是手机自带声音（中英文都行）。想换更好听的定制"帅哥音"，是第二版的事。
- **重启后他不见了**：多半是没开"自启动/后台"，见上一节。
- **想把他藏起来**：打开 App 点"把他藏起来"；想他了再点"放到桌面"。
